# 推箱子游戏 (Push Box Game)

![推箱子游戏](https://github.com/naive1024/push-box-game/raw/main/screenshot.png)

一个基于 HTML5 Canvas 和 JavaScript 的经典推箱子游戏实现。

## 🎮 游戏特性

- **多关卡设计**：包含多个精心设计的关卡
- **键盘控制**：使用方向键（↑↓←→）移动角色
- **重置功能**：随时重置当前关卡
- **步数统计**：实时显示移动步数
- **关卡切换**：支持上一关/下一关切换
- **响应式设计**：适配不同屏幕尺寸

## 🚀 如何运行

1. 克隆仓库：
   ```bash
   git clone https://github.com/naive1024/push-box-game.git
   ```

2. 在浏览器中打开 `index.html` 文件

3. 使用方向键控制角色，将所有箱子推到目标点完成关卡

push-box-game/

## 🎯 游戏规则

- 玩家（👑）可以向四个方向移动
- 可以推动箱子（📦），但不能拉动
- 将所有箱子推到目标点（🎯）即可完成关卡
- 墙壁（🧱）和障碍物无法穿越

## 💻 技术栈

- **HTML5 Canvas**：游戏渲染
- **JavaScript**：游戏逻辑
- **CSS3**：样式和动画
